# Demandes

La fiche publique d’une annonce permet maintenant d’envoyer une demande d’information ou de visite à H‑Immo. Le serveur vérifie encore la publication et la disponibilité avant l’enregistrement ; la vitrine ne crée ni réservation ni contrat.

Le formulaire demande le nom, le téléphone, un courriel facultatif et un message facultatif. Il exige l’accord pour l’utilisation des coordonnées aux fins de réponse. Les soumissions utilisent `Idempotency-Key` pour éviter les doublons lors d’une reprise réseau.
