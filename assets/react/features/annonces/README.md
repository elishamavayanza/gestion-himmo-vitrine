# Annonces

La fiche d’annonce est connectée à `GET /api/public/organizations/{slug}/listings/{uuid}` et n’affiche que les champs du DTO public. Une 404 est présentée comme annonce non disponible sans tenter d’en révéler la cause.

La fiche affiche les données publiques de l’annonce et propose un formulaire d’information ou de visite relié au contrat public d’H‑Immo. Une demande ne réserve pas le bien.
